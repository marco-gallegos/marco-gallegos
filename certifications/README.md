# Certification PDFs

Drop certificate PDFs in this folder and reference only the filename in
`js/certifications.mjs`:

```js
{
    name: "AWS Certified Cloud Practitioner",
    issuer: "Amazon Web Services",
    date: "2025-06",
    pdf: "aws-cloud-practitioner.pdf",
    url: "https://www.credly.com/badges/...",
}
```

Files here are published as-is at
`https://marco-gallegos.github.io/marco-gallegos/certifications/<filename>`.
Use lowercase, hyphenated filenames. Don't put private documents here: the
whole repository root is public.
